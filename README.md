# McDonalds-Data-Analysis
Data Cleaning and Analysing using Python and Pandas
McDonald's Menu Data Analysis using Python

📌 Project Overview

This project focuses on cleaning and analyzing McDonald's menu data using Python and Pandas. The goal is to understand menu prices, calories, nutritional values, and category-wise trends.

🎯 Objectives

- Clean and prepare the dataset.
- Identify missing values and duplicate records.
- Analyze menu prices and calorie information.
- Compare different food categories.
- Identify the highest-calorie and most expensive menu items.
- Generate charts to communicate business insights.

🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

🧹 Data Cleaning

The project includes:

- Checking missing values.
- Checking duplicate rows and item IDs.
- Cleaning column names and data.
- Identifying invalid negative nutritional values.
- Saving the cleaned dataset for further analysis.

Note: Some invalid nutritional values were converted to missing values during cleaning, so the dataset may still contain missing values.

📊 Exploratory Data Analysis

The analysis includes:

- Descriptive statistics.
- Category-wise average price and calories.
- Top 10 highest-calorie menu items.
- Top 10 most expensive menu items.
- Visualizations using bar charts.

💡 Key Business Insights

- Compare average prices across menu categories.
- Understand calorie differences between categories.
- Identify high-calorie and high-price menu items.
- Support data-driven menu and pricing decisions.

📁 Project Files

- "McDonalds_Menu_Analysis.ipynb" — Python analysis notebook.
- "mcdonalds_final_cleaned.csv" — Cleaned dataset, if included.

1. Download or clone this repository.

   "pip install pandas numpy matplotlib jupyter openpyxl"
